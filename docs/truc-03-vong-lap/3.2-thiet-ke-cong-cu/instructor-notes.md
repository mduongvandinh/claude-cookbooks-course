# Instructor notes — Buổi 3.2

**Thời lượng:** ~60 phút.

## Thông điệp chốt
1. "Mô hình chưa đủ giỏi" thường là "khung chạy chưa đủ tốt".
2. Mô tả công cụ tốt nêu: tìm gì, phạm vi, trả về gì, khi nào không dùng.
3. Đo độ chính xác chọn công cụ tách khỏi chất lượng đầu ra.

## Câu hỏi gợi mở
- "Đổi mô hình vs viết lại mô tả — cái nào lợi hơn?" (nạp câu hỏi vàng).
- "Một công cụ nên làm mấy việc?"

## Điểm hay vấp
- Mô tả mơ hồ/đồng nghĩa. Công cụ ôm đồm. Không đo chọn công cụ riêng.

## Gợi ý demo
Chạy agent với mô tả tồi (acc ~0.55) → viết lại mô tả → acc nhảy vọt, chi phí bằng không.

## Nạp bộ câu hỏi vàng
- "Agent chọn sai công cụ. Lỗi ở mô hình hay mô tả công cụ? Chứng minh ra sao?"

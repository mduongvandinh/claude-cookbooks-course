# Instructor notes — Buổi 3.1

**Thời lượng:** ~60 phút.

## Thông điệp chốt
1. Ba dấu hiệu cần vòng lặp: số bước không biết trước, phụ thuộc bước trước, có tín hiệu tự sửa.
2. Mặc định pipeline tất định — rẻ, dễ gỡ, đúng hơn.
3. Dựng cả hai bản rồi đo, đừng tranh luận.

## Câu hỏi gợi mở
- "Ba dấu hiệu thật sự cần agent là gì?" (nạp câu hỏi vàng).
- "Chi phí ẩn của agent gồm gì?"

## Điểm hay vấp
- Dùng agent cho tác vụ số bước biết trước. Bỏ qua chi phí ẩn.

## Gợi ý demo
Lấy một tác vụ, dựng bản tất định (chain) và bản agent, so chất lượng/độ trễ/chi phí.

## Nạp bộ câu hỏi vàng
- "Khi nào KHÔNG nên dùng agent? Cho ba dấu hiệu."

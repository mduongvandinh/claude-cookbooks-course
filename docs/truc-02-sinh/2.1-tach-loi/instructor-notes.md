# Instructor notes — Buổi 2.1

**Thời lượng:** ~60 phút.

## Thông điệp chốt
1. Trung thành và hữu ích là hai chỉ số khác nhau, có thể ngược chiều.
2. Thí nghiệm cô lập (context hoàn hảo) đo trần của phần sinh.
3. Citations API cho trích dẫn kiểm chứng được, khác prompt "hãy trích dẫn".

## Câu hỏi gợi mở
- "Một câu trả lời trung thành mà vô dụng — cho ví dụ."
- "Vì sao trích dẫn do prompt sinh không đáng tin?"

## Điểm hay vấp
- Gộp hai chỉ số. Bỏ thí nghiệm cô lập. Tin trích dẫn prompt.

## Gợi ý demo
Chạy Citations API live, chỉ `.citations` trên khối text.

- "Trung thành và hữu ích khác nhau chỗ nào?"

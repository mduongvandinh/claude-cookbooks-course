# Bài tập — Buổi 3.2

## Core — Viết lại mô tả công cụ
**Dự đoán trước:** viết lại mô tả sẽ nâng độ chính xác chọn công cụ từ 0.55 lên bao nhiêu?

Nhiệm vụ: lấy ba công cụ mô tả tồi, viết lại (tìm gì/phạm vi/trả về/khi nào không dùng), đo độ chính xác chọn
công cụ trước/sau.

**Tiêu chí đạt:** hai con số trước/sau; chi phí sửa ~0.

## Đi sâu — Đổi mô hình vs viết lại
**Dự đoán trước:** đổi mô hình nâng được bao nhiêu so với viết lại mô tả?

Nhiệm vụ: so ba cách — giữ mô tả tồi + đổi mô hình mạnh; viết lại mô tả + mô hình cũ; cả hai.

**Tiêu chí đạt:** bảng so ba cách; kết luận cách nào hiệu quả/chi phí tốt nhất.

## Capstone — Công cụ cho trợ lý
Định nghĩa công cụ (một việc mỗi công cụ) cho trợ lý; đạt độ chính xác chọn ≥ 0.80.

**Tiêu chí đạt:** độ chính xác chọn công cụ ≥ 0.80; mỗi công cụ một việc.
